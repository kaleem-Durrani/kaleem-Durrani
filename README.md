## 🚀 What I'm Building:

### 💼 Kairos Tech — Software House
Building production-grade business solutions that have been deployed to **multiple retail businesses**:

- 🏢 **[Agora POS](https://kairos-pk.com/projects/Agora)** — Enterprise Point of Sale with Integrated Accounting  
  Full double-entry bookkeeping system that eliminates manual reconciliation. Real-time financial reporting, multi-method inventory tracking, role-based access control, and fiscal period management.

- 🧵 **[SJ Lace POS](https://kairos-pk.com/projects/sj-lace)** — Complete POS & Inventory Management  
  Specialized system for lace and fabric retail with FIFO inventory tracking, comprehensive financial platform, and multi-user support with role-based permissions.

**Key Features Across Products:**
- 📊 Integrated accounting engines with GL/sub-ledger architecture
- 📦 Multi-method inventory (per-item, by-weight, by-length, serialized)
- 🔄 Offline-first with network synchronization capabilities
- 🌍 Cross-platform desktop apps (Windows, macOS, Linux)
- 🔐 Enterprise-grade security with RBAC and audit trails
- 📈 Real-time financial reporting (P&L, Balance Sheet, Cash Flow)
